# Fork legacy docs

These Markdown files were inherited from the repository this project was
originally forked from (an "agent skills" collection). They describe that
other project's skill workflows, personas, and setup guides — **not ARIA AI**.

They were moved here (out of the repo root) so they no longer masquerade as
ARIA documentation. Their internal cross-references still resolve because
they were moved as a group.

- Do not treat them as guidance for working on ARIA AI. The authoritative
  agent guides are `/AGENTS.md` and `/CLAUDE.md` at the repo root.
- Safe to delete entirely once nobody needs the historical reference.
